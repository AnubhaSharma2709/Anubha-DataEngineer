# Icon sources

- `microsoftazure.svg` and `microsoftexcel.svg` are local SVG copies from the Simple Icons v12 CDN. They are kept locally because those Microsoft brand slugs are no longer available from the current Simple Icons CDN endpoint used for other brand marks.
- `powerbi.svg` comes from Microsoft's [Power BI icons repository](https://github.com/microsoft/PowerBI-Icons).
- Social platform marks in `social/` are local SVGs downloaded from Simple Icons v12. They are shown even while profile URLs remain unconfigured.
- Other brand marks use Simple Icons (`https://cdn.simpleicons.org/`) or Devicon for Java, CSS3 and LinkedIn.
- The Azure certification line uses the Microsoft Azure mark alongside its text label. The page does not claim Azure production experience.
- Lucide supplies interface and concept icons.

Replace or update icon paths in `js/main.js` if the source assets change.

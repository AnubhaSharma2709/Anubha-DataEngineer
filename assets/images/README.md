# Images

The website uses optimized WebP versions of the portrait and the personal photographs supplied by Anubha. The original uploads remain in the Downloads folder.

- `anubha-profile.webp`: used beside the hero heading. CSS fixes its display size at 62 × 62 px on desktop and 50 × 50 px on mobile.
- Other named WebP files: the vertical photo carousel in the home page's “Curious by Design” section. Paths and alt text live in `personalPhotos` in `js/data.js`.
- Achievement bento photographs are intentionally left as replaceable placeholders.
